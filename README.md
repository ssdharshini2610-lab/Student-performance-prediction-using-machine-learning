# Student Performance Prediction Using Machine Learning

## Project Overview
This project predicts student academic performance using Machine Learning techniques based on factors such as attendance, study hours, and previous marks.

## Objectives
- Predict student performance.
- Analyze factors affecting academic results.
- Help educators identify students who need support.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Flask
- CSV Dataset

## Project Modules
1. User Management
2. Student Data Management
3. Performance Prediction
4. Result Analysis
